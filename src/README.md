# Source Code Layout

This directory contains code that is not organized as an original thesis package under `packages/`.

- `octave/`
  Thesis-owned MATLAB/Octave prototypes, experiment drivers, and helper functions.

- `MBC/`
  Vendored external R package for multivariate climate-model bias correction.

- `rSVD/`
  Vendored external R package for randomized matrix decompositions.
