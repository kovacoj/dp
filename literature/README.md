## Notes

- `literature/` currently contains a strong mixed-precision local subset and some climate PDFs, but several core RandNLA references cited in the manuscript are not stored locally yet.
- The most important local thesis-facing PDF in the present library is `mixed-precision/2602.04348v1.pdf` for Carson (2026).
- Climate-side local PDFs currently include Maraun (2016), Vrac and Friederichs (2015), and Vrac (2018), which complement the Cannon references even though only the Cannon-family items are indexed in the table above.
- If a second Carson-Dauzickaite 2024 paper is later added to `bibliography.bib`, this table should be split into explicit `2024a` and `2024b` rows with manuscript-consistent labels.
