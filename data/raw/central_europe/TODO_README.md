# Central Europe Data Placeholder

This directory is reserved for Central Europe climate data used by the final
application-facing experiments and the thesis climate chapter.

## Required Files

- historical model data
- future model data
- observational reference data

## Required Metadata

- variable names and units
- time encoding and calendar conventions
- missing-value conventions
- spatial coordinates
- source tags and provenance notes

## Interim Fallback

Until the real Central Europe data arrive, the CCCma dataset bundled with the
`MBC` R package serves as the smoke-test fallback for the climate-application
pipeline.
